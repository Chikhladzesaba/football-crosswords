მოკლედ

ანგარიშები არ გვაქვს და შენგან პირად ინფორმაციას არ ვითხოვთ.

რა ინახება შენს მოწყობილობაში

შენი პროგრესი, ამოხსნილი თამაშები და სტატისტიკა შენსავე მოწყობილობაში, ბრაუზერის მეხსიერებაში ინახება. ჩვენ მათ ვერ ვხედავთ. ბრაუზერის მონაცემებს თუ წაშლი, ისინიც წაიშლება.

ვიზიტების სტატისტიკა

ვიზიტებს ორი სერვისით ვითვლით.

Cloudflare Web Analytics გვიჩვენებს ვიზიტების სტატისტიკას და ასევე იუზერის მდებარეობას. Cloudflare-ის თქმით, ის cookie-ებსა და ბრაუზერის მეხსიერებას არ იყენებს და პირად მონაცემებს არ აგროვებს.

Google Analytics-ის დახმარებით ვიგებთ, რომელ თამაშებს თამაშობენ და როგორ იყენებენ საიტს. ეს სერვისი იყენებს cookie-ებს და გვეხმარება ვებსაიტის გაუმჯობესებაში.

შენი არჩევანი cookie-ებზე

მთავარ გვერდზე გეკითხებით, ეთანხმები თუ არა cookie-ების პოლიტიკას. შეგიძლია უარი თქვა და მის გამოყენებას შევწყვეტთ.

პასუხის შესაცვლელად დააჭირე ბმულს ქუქი-პარამეტრები. კითხვა ისევ გამოჩნდება და ახლიდან აირჩევ. დეტალები იხილე Google-ის კონფიდენციალურობის პოლიტიკაში.

ჰოსტინგი

საიტი GitHub Pages-ზეა განთავსებული. ისევე როგორც ნებისმიერი ჰოსტინგი, GitHub-იც შეიძლება ინახავდეს ტექნიკურ მონაცემებს, მაგალითად IP მისამართს, როცა გვერდს ხსნი. დეტალებისთვის იხილე GitHub-ის კონფიდენციალურობის პოლიტიკა.

გაზიარება

როცა შედეგს აზიარებ, ტექსტი და ბმული იმ აპს ან საიტს გადაეცემა, რომელსაც აირჩევ, მაგალითად WhatsApp-ს ან Facebook-ს. ბმულს პატარა ნიშანი აქვს (utm_source=share), რომ გაზიარებიდან მოსული ვიზიტები დავთვალოთ. ამ აპებსა და საიტებს საკუთარი კონფიდენციალურობის წესები აქვთ.
